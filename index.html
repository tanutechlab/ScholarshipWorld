📌 Important: Verify Before You Apply

This website is an independent scholarship directory, not an official government or university service. Its starter records link to scholarship providers and official information sources. A working official link does not mean a scholarship is currently open, that every eligibility rule has been verified for the current year, or that funding is guaranteed.

Scholarship amounts, age limits, eligible nationalities, language tests, deadlines and participating universities can change. Always read the latest official program guidelines. Requirements that are not established in this directory are marked as unknown or variable rather than assumed to be satisfied.
